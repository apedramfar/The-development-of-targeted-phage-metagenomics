# The development of targeted phage metagenomics

## Project overview

This repository contains bioinformatics workflows, analysis scripts, and supporting documentation developed as part of my PhD research at the University of Leicester.

The project investigated the use of bacterial minicells as a selective platform for enriching bacteriophages that interact with bacterial hosts from complex environmental viromes.
By combining with metagenomic sequencing and computational analyses, this research aimed to improve the detection and characterisation of phages, investigate host-associated viral diversity, and advance our understanding of phage-host interactions in complex microbial communities.

## Bioinformatics analyses

The repository includes scripts and workflows supporting several aspects of viral metagenomic analysis:

**Reference genome comparisons:** Mash-based comparisons against the INPHARED2 phage reference dataset.

**Genome similarity and quality assessment:** BLASTn-based average nucleotide identity (ANI) analysis and supporting CheckV analyses.

**Differential enrichment analysis:** Centred log-ratio (CLR)-based analysis to investigate changes in viral abundance between experimental conditions.
