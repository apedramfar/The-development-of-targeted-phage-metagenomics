# The development of targeted phage metagenomics

Bioinformatics workflows and analysis scripts supporting minicell-based enrichment and host-specific phage identification from complex viromes.

## Repository structure

- `scripts/mash_inphared/` — INPHARED2 Mash comparison workflows
- `scripts/ani_checkv/` — ANI analysis using BLASTn and CheckV supporting scripts
- `scripts/clr_enrichment/` — CLR-based enrichment analysis
- `methods/` — bioinformatics method notes
- `docs/` — supporting documentation

## Data availability

Large sequencing datasets, reference databases, and supplementary outputs are not stored in this repository and are available through the associated data repositories and supplementary resources.
